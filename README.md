# Codewise Clinical Timeline

A SMART on FHIR application that visualizes patient clinical history as an interactive, source-linked timeline.

## Overview

Codewise Clinical Timeline helps clinicians rapidly understand complex patient cases during chart review, rounding, and handoff. The application reads patient data via the FHIR R4 API and presents it as a chronological clinical map, where every generated summary is traceable back to its underlying source documentation in the EHR.

## Status

This project is currently in early development (sandbox prototype) and is not production-ready. It uses synthetic and Epic FHIR sandbox test data only — no real patient data (PHI) is processed.

## Audience

Designed for use by clinicians and administrative users within Epic-integrated healthcare environments.
